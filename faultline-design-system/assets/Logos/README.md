# Logos

Two versions of the Faultline mark. Pick by the ground you are placing it on, not by the theme name.

| File | Use on | Notes |
| --- | --- | --- |
| `faultline-mark-ink.svg` | light grounds (`surface-base` light, paper, print) | ink strata, `state-live` light ochre |
| `faultline-mark-paper.svg` | dark grounds (`surface-base` dark, the product, slides) | paper strata, `state-live` dark ochre |

Both are 64×64 viewBox, no fill on the canvas, so they sit on any ground. Clear space is one band height (11 units). Minimum 24px — below that use the wordmark alone.

There is no gradient version, no rounded-square app-icon version and no all-caps wordmark. If a deck or a README needs something that is not here, draw it from `tokens.json` rather than recoloring the mark.
